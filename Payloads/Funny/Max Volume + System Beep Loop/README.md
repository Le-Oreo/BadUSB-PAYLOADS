# 🔊 Max Volume + Beep Loop

A BadUSB prank that maxes out the system volume and plays an annoying beep every 5 seconds.

## ⚠️ Disclaimer

**Friendly prank only.** Do NOT use in:
- Libraries / quiet places
- Work / school
- Anyone with headphones (loud beep = their ears)

## 📋 What It Does

1. Sets system volume to 100%
2. Plays a 2000Hz beep (500ms) every 5 seconds
3. Runs forever until stopped

## 🛑 How to Stop

1. `Ctrl + Shift + Esc` → Task Manager
2. Find "Windows PowerShell"
3. Right-click → End Task
