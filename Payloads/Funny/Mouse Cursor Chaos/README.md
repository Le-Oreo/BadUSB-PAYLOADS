A BadUSB prank that makes the cursor move randomly across the screen, making the computer feel possessed.

## ⚠️ Disclaimer

**Friendly prank only.** Do NOT use on work, school, or anyone who won't laugh.

## 📋 What It Does

- Cursor jumps to a random position every 100ms
- Tracks the entire virtual screen (multi-monitor friendly)
- Runs forever until manually stopped

## 🛑 How to Stop

1. `Ctrl + Shift + Esc` → Task Manager
2. Find "Windows PowerShell"
3. Right-click → End Task
